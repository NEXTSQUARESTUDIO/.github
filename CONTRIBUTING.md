# Contributing to Next Square Studio

Thanks for helping us improve our work.

## Start with the right place

- For a bug or idea about a repository, check its existing issues, then choose the matching issue template.
- For help with a game or a business enquiry, see [Support](SUPPORT.md).
- Discuss a large change before implementing it so the scope and expected result are clear.

## Make a focused change

1. Read the repository's README and any project-specific guidance.
2. Work on a separate branch with a short descriptive name, such as `fix/menu-layout`.
3. Keep the change focused on one problem. Preserve unrelated work.
4. Run the relevant checks and, for visual changes, check the result on the affected screen or device.
5. Open a pull request describing the problem, the change, and what you actually verified. Link its issue when there is one.

State any checks you could not perform. A successful build alone does not prove that a game or app works on a physical device.

## Keep collaboration clear

Be kind, specific, and constructive. Do not include passwords, signing keys, private user information, or proprietary third-party assets in an issue or pull request. Follow the repository's license and asset permissions.

Repository-specific instructions take precedence over this general guide.
