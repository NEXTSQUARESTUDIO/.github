# Reporting a security concern

Please report suspected vulnerabilities privately to **[contact@nextsquarestudio.com](mailto:contact@nextsquarestudio.com)** with the subject **Security report**.

Include the affected product or repository, version, the potential impact, and concise reproduction steps. Remove passwords, tokens, and personal data from examples and logs.

Do not publish vulnerability details in a public issue. Do not access other people's data, disrupt services, or test beyond systems you are authorized to use.

This page provides a reporting contact. It does not promise a response deadline, a bug bounty, or permission to test systems.
